# trellis.cpp (archived)

`trellis.cpp` is retired from the active `modal-3D` model set because its latency and raw mesh size are not competitive enough for the intended interactive workflow.

The worker implementation is preserved here for reproducibility. Historical evidence is intentionally kept in place and is not rewritten:

- `docs/TRELLIS_CPP.md`
- `benchmarks/trellis.cpp-l40s-2026-08-22.json`
- `benchmarks/COMPARISON.md`
- `benchmarks/pages-l40s-2026-08-23.json`
- `docs/ENGINEERING_RETROSPECTIVE.md`

The deployed Modal app/weight volume may still exist as archived infrastructure, but the active gateway and current Pages model list no longer route to it.
